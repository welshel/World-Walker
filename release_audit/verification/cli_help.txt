usage: run_pipeline.py [-h]
                       (--input-topdown INPUT_TOPDOWN | --scene-prompt SCENE_PROMPT)
                       [--config CONFIG] --output OUTPUT
                       [--start-stage START_STAGE] [--stop-stage STOP_STAGE]
                       [--resume] [--allow-anchor-alignment-fail]
                       [--force-stage FORCE_STAGE] [--gpu GPU]
                       [--enable-seedvr2 | --disable-seedvr2] [--dry-run]

World-Walker research pipeline: top-down image or natural-language input.

optional arguments:
  -h, --help            show this help message and exit
  --input-topdown INPUT_TOPDOWN, --input INPUT_TOPDOWN
                        existing topdown image (legacy --input alias)
  --scene-prompt SCENE_PROMPT
                        natural-language garden scene description
  --config CONFIG
  --output OUTPUT
  --start-stage START_STAGE
  --stop-stage STOP_STAGE
  --resume
  --allow-anchor-alignment-fail
                        continue after a failed FLUX anchor alignment audit;
                        use only after visually inspecting the anchor/proxy
                        comparison
  --force-stage FORCE_STAGE
  --gpu GPU
  --enable-seedvr2
  --disable-seedvr2
  --dry-run             validate configuration and print planned stages
                        without running models
